# Pebble — Brand Book

> The decisions every Pebble-branded asset gets right, by default.
> Read this before shipping anything customer-facing.

## 1. The brand in one sentence

**Pebble makes building a beautiful website feel easy — so anyone can turn an idea into a real, working site.**

### The poetic version (use sparingly, in hero moments)

**"If you can dream it, you can hold it."**

*(From Gemini's brand brief. Use this for the punchline at the bottom of hero sections, the social media bio, the home-screen app tagline. Not for body copy — too poetic for daily use, but perfect for the brand's soul-line.)*

## 1b. The mission — Radical Inclusivity

Pebble exists for the people other tools forgot. The 55-year-old real estate agent who's been told to "just use Squarespace." The retiree launching a venture who's intimidated by Lovable. The aunt who wants to share her poetry but doesn't know what a "deployment" is.

**The technology adapts to the human, not the other way around.** Everyone has ideas. Everyone deserves to bring them to life in the palm of their hands.

That's the north star. Every product decision rolls up to this.

## 2. Brand essence — the pebble metaphor

The name "Pebble" is the strategy.

```
A pebble is:
  ▪  Small, considered, perfectly formed
  ▪  Smoothed by water — natural, organic, never harsh
  ▪  Familiar — you've held one a hundred times
  ▪  Quietly premium — like a beautiful object in your pocket
  ▪  Approachable — not a monument, not a skyscraper

That's what our product should feel like to use.
```

This metaphor governs every visual + voice decision.

## 5. Colors

A warm, accessible palette inspired by river stones, soil, and sunlight — natural, grounded, never aggressive. Tuned for the inclusivity mission: high contrast, warm energy, easy on aging eyes.

```
TOKEN         HEX        ROLE                             USE WHEN
─────────────────────────────────────────────────────────────────────
Pebble Sand   #FAF8F3    Primary background (light)       Marketing site,
                          Warm, paper-feel, editorial      app background

Pebble Stone  #2C2C2A    Primary ink (dark warm gray)     Body text,
                          Reads as black but is softer     headlines

Pebble Spark  #C8A96E    PRIMARY ACTION (warm amber)      Buttons, CTAs,
                          Warm, optimistic, "go" energy    primary clicks
                          High contrast, easy to spot      ←── promoted

Pebble River  #5E7A6E    Success / supporting (sage)      Success states,
                          Calming, natural, secondary      "saved" indicators

Pebble Earth  #C57E5A    Warm highlight (terracotta)      Small decorative
                          Optional, used sparingly         moments — never
                                                           body, never CTAs
                                                           ←── new token

Pebble Mist   #E8E2D5    Borders, dividers (light gray)   Hairline rules,
                          Subtle, never aggressive         input borders
```

### Rules

```
✓ Sand + Stone are the foundation everywhere
✓ Spark (amber) is the ONE color that screams "click here" — primary
   CTAs only. Maximum one Spark element per visible screen.
✓ River (sage) is for success / saved / safe states
✓ Earth (terracotta) is decorative warmth — used sparingly
✓ Mist is structure — hairlines, dividers, input borders
✗ No neon
✗ No pure black (#000000) — always Pebble Stone (prevents eye strain)
✗ No pure white (#FFFFFF) — always Pebble Sand (warmer, calmer)
✗ No gradients except inside generated sites (liquid-glass utility)
✗ No more than 2 accent colors visible at once
```

### Accessibility — non-negotiable

Pebble's audience is older, sometimes vision-impaired. We hold to **WCAG AAA contrast standards**, not just AA.

```
Body text on Sand:       Stone (#2C2C2A) → 13.5:1   ✓ AAA
Spark button text:       Stone (#2C2C2A) on Spark   → 6.2:1  ✓ AAA-large
River button text:       Sand (#FAF8F3) on River    → 5.4:1  ✓ AA
Mist borders on Sand:    decorative, no text       → exempt

When in doubt: run the pair through https://webaim.org/resources/contrastchecker/
and target 7:1 minimum for body text, 4.5:1 for large text and UI.
```

## 6. Typography

```
ROLE              FAMILY                  WHY
─────────────────────────────────────────────────────────────────────
Display           Inter                   The engine's foundation type.
                  (300/400/500/600)       Modern, neutral, warm.
                                          Consistency across product.

Body              Inter                   Same family, lighter weight.

Editorial accent  Fraunces or             Used sparingly: pull-quotes,
                  Cormorant Garamond      drop caps, hero personality.
                                          Adds humanity + warmth.

Mono              IBM Plex Mono           Version numbers, "powered by
                                          Pebble" tags, technical badges.
```

### Rules

```
✓ Inter is the default — it's the engine foundation, it's the brand
✓ Editorial accent ONLY for italicized pull-quotes or drop caps
✓ Mono ONLY for badges, version strings, code blocks
✗ Never set body text in a serif
✗ Never use more than 3 weights of Inter in the same screen
✗ Never mix Pebble's branding with the DNA system's display fonts —
   those belong to GENERATED sites, not Pebble itself
```

### Sizes — built for older eyes

The Pebble audience is older. Comfortable reading at arm's length is the floor, not the ceiling.

```
ROLE               MIN SIZE      DESKTOP DEFAULT     MOBILE DEFAULT
─────────────────────────────────────────────────────────────────────
Body text          18px          18px-20px           18px
                   ↑ NEVER smaller. 16px is too small for the audience.

Caption / mono     14px          14px                14px
                   ↑ For brand-mono tags, version numbers, etc.
                     Even the small text is still readable.

Sub-headline       22px          22px-28px           22px

Section heading    32px          36px-48px           32px

Hero headline      48px          60px-128px          48px-56px
```

### Weight rule

```
✗ No thin weights (100, 200, 300) — disappears on aging displays
✓ Body and UI text: 400 (regular) minimum, 500 (medium) when emphasis
✓ Headlines: 400 (regular) or 500 — never lighter
✓ Editorial italic: 400 only (Fraunces italic regular)
```

## 7. Logo + wordmark direction

**Phase 1 (now): typographic wordmark.** Inter Bold (700), all-lowercase, slightly negative tracking.

```
   pebble
```

**Phase 2 (next): minimalist stone icon paired with the wordmark.**

Per the inclusivity-first brand direction, a small organic icon will eventually accompany the wordmark. Direction:

```
✓ A simple ovoid silhouette suggesting a river-smoothed stone
✓ Asymmetric, hand-drawn feeling — not geometric perfection
✓ Solid fill in Pebble Stone (#2C2C2A)
✓ Single color, no gradient, no shadow
✓ Reads as "natural object" — never as "tech logo"

✗ No automotive elements, computer chips, or glowing AI nodes
✗ No abstract geometric shapes that read as "infinity loop" or "swoosh"
✗ No outlined-only marks (looks corporate)
✗ No type-only marks with a dot or accent that reads as "AI sparkle"
```

Until we commission the icon, the wordmark stands alone.

### Variations

```
PRIMARY            "pebble" in Pebble Stone (#2C2C2A) on Pebble Sand
DARK MODE          "pebble" in Pebble Sand (#FAF8F3) on Pebble Stone
ICON-PAIRED        [pebble icon]  pebble   (when icon ships)

NEVER
✗ Don't outline the wordmark
✗ Don't italicize it
✗ Don't tagline-attach it ("pebble | websites made easy")
   — let the wordmark stand
✗ Don't pair with anything that looks like an "AI" mark
   (glowing dots, lightning bolts, circuit lines)
```

Always leave at least the height of the "p" of clearance on all sides.

## 8b. Product UX principles (applies to dashboard + editor)

These four principles govern the PRODUCT (the dashboard, the visual editor, the in-app help). They don't apply to the marketing site directly — but every screen we build for paying customers must pass these tests.

### Voice-first interaction

**"Tap to Talk" is the primary input. Typing is secondary.**

```
WHY        Older users, users with arthritis, users hesitant about keyboards.
           A 65-year-old will gladly say "make my hero a coffee shop" but
           will hesitate to type a "prompt."

WHERE      Every text-input screen in the dashboard has a microphone button
           AT LEAST as prominent as the text field.

           Voice → transcribed → same path as typed input.

           User can switch between voice and text mid-flow.
```

### The "One Thing" Rule

**Every screen presents one clear action or question at a time.**

```
✗ DON'T    A signup screen with email, password, name, company,
           role, plan picker, and "I agree to terms" all on one
           screen.

✓ DO       Step 1: "What's your email?" → next
           Step 2: "Choose a password." → next
           Step 3: "What's your name?" → next
           ... etc.

           Multi-step is friendlier than dense forms for this audience.
           A progress dot at the top reassures: "you're 3 of 5 steps in."
```

### Forgiving Architecture

**Visually communicate: nothing can be broken. Everything is undoable.**

```
✓ Every destructive action shows a soft "are you sure?" with two
   options. Default focus is "no, keep it."

✓ Deleted things go to a Trash bin, not the void. 30-day recovery.

✓ Every save shows a quiet ✓ Saved indicator. The user isn't left
   wondering if the action worked.

✓ Animations are reassuring (soft fade-out for delete, gentle
   slide-in for create). Not jarring.

✓ Error messages NEVER say "Error" or "Failed."
   ✗ "Error: Network request failed"
   ✓ "We couldn't reach our server just now. Try again in a moment."
```

### Guided onboarding (no blank canvas)

**Empty text boxes are a UX failure. Always offer curated suggestions.**

```
✗ DON'T    [empty text box] "Describe your business"
           (the user freezes)

✓ DO       "What are you building?"
           ○ A site for my real estate business
           ○ A page for my poetry collection
           ○ A booking page for my therapy practice
           ○ Something else — tell me about it
           
           (One-tap options that get them to the next screen
            in under 3 seconds.)
```

These four principles are mandatory for product UX. They're optional for marketing pages (marketing is allowed to have full landing-page density).

## 9. Patterns (the visual moves Pebble repeats)

These are the small details that make a Pebble asset recognizable across the site, the app, the docs, the social posts.

```
1.  Rounded corners.
    Cards: 12px radius. Buttons: 8px. Input fields: 8px.
    Always rounded — never sharp. Reference: a pebble.

2.  Hairline dividers (Pebble Mist, 1px).
    Sections separated by hairlines, never by colored bands or shadows.

3.  Generous whitespace.
    Default vertical padding between sections: 80px desktop, 56px mobile.
    Whitespace IS the design.

4.  One-color emphasis.
    Each section has ONE thing that breaks the page in color
    (a CTA in Pebble River, a pull-quote in Pebble Spark).
    Never multiple emphasis points fighting.

5.  Subtle motion only.
    Opacity fades. Gentle hover transitions. No bouncing,
    no aggressive scroll-jacking. Speed: ease-out, 300-500ms.

6.  Liquid-glass surfaces (reserved for generated sites).
    The .liquid-glass utility from the engine foundation belongs to
    GENERATED sites, NOT Pebble's own marketing. Don't dilute it.
```

## 11. What's on-brand vs off-brand (gut-check examples)

```
ON-BRAND (do more of this)
  ▪  A photo of a real coffee shop owner reading her new Pebble site
     on her phone, smiling. Natural light. Warm tones.
  ▪  A clean before/after: a generic Wix template → a Pebble site.
  ▪  A 2-minute video of a 60-year-old answering the quiz live.
  ▪  Plain-English testimonials. "I cried when I saw it." (real quotes)
  ▪  Editorial newsletter explaining one design principle per issue.

OFF-BRAND (stop us from doing this)
  ✗  Stock photo of "diverse team around a laptop, all smiling at screen"
  ✗  Robot/AI illustrations (we're about humans, AI is the tool)
  ✗  "Disrupting the industry" / "10x your business" / "AI-powered"
  ✗  Saturated gradients, neon accents, glassmorphism on Pebble itself
     (glassmorphism is reserved for generated sites — different audience)
  ✗  Buzzword-heavy press release tone
```

## 12. When in doubt

```
1.  Read the sentence out loud.
    Would a friend say this? If not, rewrite.

2.  Cover up the design.
    Does the message land in plain text alone? If not, the design
    is doing too much work.

3.  Show it to a non-technical friend.
    Confused or hesitant? Pebble has failed at its job.

4.  Compare it to a Lovable / Base44 page.
    Does Pebble feel calmer, warmer, more human? If not, we drifted.
```
