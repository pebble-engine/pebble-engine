Pebble Engine needs one API key to build websites for you. It takes about sixty seconds.
1
Pick your provider

Gemini is recommended — you probably have free tokens through Google Ultra. Claude is the alternative if you prefer Anthropic.

2
Get your API key

Go to Google AI Studio, sign in with your Google account, and create an API key. It's free.

3
Paste it here

Copy the key from the site and paste it in the box below.

Your API key is saved to a .env file inside the Pebble Engine folder on your computer. It never leaves your machine.
