# Corpus HVAC

Synthetic broken build for repair-loop regression tests.

## Deploy

1. Push this directory to a new GitHub repo.
2. Import the repo at https://vercel.com/new.
3. Add `RESEND_API_KEY`, `CONTACT_FROM_EMAIL`, `CONTACT_TO_EMAIL` in the Vercel dashboard.

## What This Site Does NOT Include

- Real-time technician dispatch (recommended: Jobber).
- Payment processing (recommended: Stripe Payment Links).
