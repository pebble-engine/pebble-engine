# Design craft

- **One focal point per section** — hero headline + one CTA, not three competing messages.
- **Generous whitespace** between sections; avoid cramming cards edge-to-edge on mobile.
- **Typographic hierarchy**: one clear h1 per page; h2 for sections; body never competes with headlines.
- **Mobile-first**: stack columns on narrow viewports; no horizontal scroll except intentional carousels.
- **Avoid dense card grids** for service lists on mobile — prefer full-bleed alternating panels when Layout DNA allows.
- **Consistent spacing scale** (8/16/24/32/48/64) — align padding across sections.
- **Accent color sparingly** — CTAs, links, key stats; not every heading.
