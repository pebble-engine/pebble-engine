# Universal design (generated sites)

- Body text **16px minimum** on mobile; line-height **1.5–1.65**.
- Primary buttons and links: **min 44×44px** tap area; generous spacing between tappable items.
- **High contrast** text on backgrounds (WCAG AA); avoid light-gray-on-white body copy.
- **Plain language** in headings and CTAs — "Call us" not "Initiate contact"; short sentences.
- One primary action per screen; secondary actions visually quieter.
- Forms: visible labels (not placeholder-only), large inputs, clear error text.
- Respect `prefers-reduced-motion` — animations are subtle or off when requested.
