# P3 — "My Brand Kit" (design-system lite) Implementation Plan

> **For agentic workers:** superpowers:executing-plans (inline). Steps use `- [ ]`.

**Goal:** Let a returning owner pin a brand kit (colors, font, voice) once so every new build inherits a consistent identity.

**Architecture:** Mirrors P1. Per-account brand kit stored at `output/.users/<uid>/brand_kit.json` ({primary_color, accent_color, font, voice}). `pebble/brand_kit.py` loads/saves + renders a `brand_kit_block` directive. Injected into the full build prompt via a new `{brand_kit_block}` slot (next to `{knowledge_block}`). Managed via GET/POST `/api/account/brand-kit` + a Settings card. Applied at generation time by the LLM (use these tokens/font/voice) — no deep Style-DNA surgery.

**Tech Stack:** Python stdlib, str.format prompt, Next.js v3.

from pebble import brand_kit as bk

def test_empty_kit_renders_blank():
    assert bk.render_brand_kit_block({}) == ""

def test_render_includes_colors_font_voice():
    out = bk.render_brand_kit_block({"primary_color":"#1F6FEB","accent_color":"#F59E0B","font":"Inter","voice":"warm, plain"})
    assert "BRAND KIT" in out and "#1F6FEB" in out and "Inter" in out and "warm, plain" in out

def test_render_is_strformat_safe():
    out = bk.render_brand_kit_block({"voice":"a {b} c"})
    assert "{" not in out and "}" not in out

def test_sanitize_validates_hex_and_caps_lengths():
    k = bk.sanitize_kit({"primary_color":"not-a-color","accent_color":"#abc","font":"x"*200,"voice":"y"*5000})
    assert k["primary_color"] == ""            # invalid hex dropped
    assert k["accent_color"] == "#abc"          # valid short hex kept
    assert len(k["font"]) <= bk.MAX_FONT and len(k["voice"]) <= bk.MAX_VOICE

def test_account_round_trip(tmp_path):
    bk.save_account_brand_kit(tmp_path, "u1", {"primary_color":"#000000"})
    assert bk.load_account_brand_kit(tmp_path, "u1")["primary_color"] == "#000000"
