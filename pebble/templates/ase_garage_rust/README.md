ase_garage_rust — color variant of `ase_garage`. Warm rust palette: deep-brown background (replacing slate), rust-orange shimmer CTAs (replacing hazard yellow), burgundy emergency band (replacing brick red). Same single-page layout (hero stat panel, services strip, drop & go process, before/after slider, estimate form). Intended for independent shops that want warm, brick-and-leather, old-school garage energy instead of cool industrial slate.
